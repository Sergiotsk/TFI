# Discovery

Fase de **descubrimiento**: entender el problema y a los actores reales **antes**
de escribir una línea de código.

> **Metodología aplicada: Design Thinking.**

## Las 5 fases y dónde viven

| Fase | Qué es | Dónde |
|---|---|---|
| 1. **Empatizar** | Entender a los actores del proceso | [`entrevistas/`](entrevistas/) |
| 2. **Definir** | Sintetizar el problema (personas, POV) | `sintesis.md` *(pendiente)* |
| 3. **Idear** | Explorar y rankear soluciones | [`ideacion/`](ideacion/) |
| 4. **Prototipar** | Construir prototipos navegables | *(más adelante)* |
| 5. **Testear** | Validar con usuarios reales | *(más adelante)* |

## Por qué la carpeta se llama `discovery` y no `design-thinking`

`discovery` nombra la **etapa** (el rol); Design Thinking es el **método** (la
herramienta). Nombrar por el rol mantiene la estructura durable si el proyecto
crece a producto y suma nuevos ciclos de descubrimiento. El método queda
explícito acá, en el contenido, donde la cátedra lo necesita ver.
