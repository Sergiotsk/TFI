# Producto

Historias de usuario, requisitos y gestión del backlog.

## Fuente única de verdad del backlog

Para evitar duplicación y desincronización, cada cosa vive en un solo lugar:

| Qué | Dónde vive | Cambia... |
|---|---|---|
| **Tablero de tareas** (en curso / hecho) | **GitHub Projects** | todos los días |
| **Historias de usuario** (formales) | acá (`historias-de-usuario.md`, *pendiente*) | rara vez |
| **Backlog para la entrega** | §1.4 del `DOCUMENTO-SEGUIMIENTO` (foto → PDF) | se congela al final |

> El `.md` **no** duplica el tablero: las tareas dinámicas viven en GitHub
> Projects. Acá van las historias de usuario estables (formato *Como… Quiero…
> Para…*), que salen del [discovery](../discovery/).
