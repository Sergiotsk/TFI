# Prototipos

Maquetas HTML de las pantallas del postulante (bienvenida, pago, carga de documentación y estado del
trámite), hechas por Santi para validar el flujo. Corresponden a la etapa **Prototipar** de Design
Thinking y **no forman parte del código** de la solución. Para verlas, abrí `index.html` en el navegador.

**Antes:** estaban en `src/test_frontend/` y después en `src/apps/web/`.
